Android Webcam App

Available endpoints :

GET '/video'

MJPEG stream.

GET /features

Get available features. e.g.


{
    "resolutions": ["640x480","1280x720","1920x1080","3840x2160"],
    "manual_focus": true,
    "exposure_lower": -20,
    "exposure_upper": 20,
    "stream_protocol": "MJPEG"
}

Get /settings

Get current settings. e.g.


{
    "focus_mode": 0,
    "focus_distance": 0.0,
    "exposure_index": 0,
    "zoom": 1.0,
    "stream_quality": 80,
    "flip": false,
    "resolution_str": "1280x720"
    "camera": "back",
}

Get /control

Get current settings. e.g.


{
    "focus_mode": 0,
    "focus_distance": 0.0,
    "exposure_index": 0,
    "zoom": 1.0,
    "stream_quality": 80,
    "flip": false,
    "resolution_str": "1280x720"
    "camera": "back",
}

POST /settings

Set settings endpoint. Post a JSON object with the desired settings to update multiple states at once. e.g. 


{
    "focus_mode": 0,
    "focus_distance": 0.0,
    "exposure_index": 0,
    "zoom": 1.0,
    "stream_quality": 80,
    "flip": false,
    "resolution_str": "1280x720"
    "camera": "back",
}

Note:

Zoom is not supported yet. For more details check out : Github Project
